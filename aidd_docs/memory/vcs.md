# VCS

## Setup

- Main branch: `main`
- Platform: `github` (compte personnel du mainteneur)

## Branches

- Format: `type/description-courte` (ex. `feat/digest-slack`, `fix/extraction-arxiv`)
- Types in use: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`

## Commits

- Convention: Conventional Commits
- Format: `type(scope): description`, scopes `web`, `worker`, `infra`
- Rules: impératif, minuscules, 72 caractères maximum

## Commit Strategy

AI should auto commit: `never`
